# Roadmap

This plugin will allow the user to connect ACF repeaters and ACF relations to Elementor Loop Grids.

When using a Loop Grid, the user will be able to select the ACF name of the repeater or Relationship to be used as the data source for the Loop Grid as a config option on the Loop Grid. The data source for the Loop Grid will be the ACF repeater or Relationship with the selected name on the object in the current query.

When creating the templates, the user will be able to select repeater subfield names as dynamic tags for text, image, etc. widgets. The users will be able to select subfields for any repeater or Relationship, since templates could be used in multiple locations.
